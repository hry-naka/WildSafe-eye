# PoC試験仕様書（詳細化版）

## 目的
- 近距離（〜100m以内）でFalse Negative率0%必達を確認
- 遠距離（100m以上）のFN率を参考値として評価
- 誤検知率（FP率）とヒステリシス挙動を副次的に確認

---

## 試験手順

### 1. データ準備
- 熊映像（ネット動画）、類似動物（人間・犬）、環境映像（枝揺れ・雨・雪）を収集
- イベント単位＋キーフレーム方式でラベリング（5〜10枚/イベント）
- 距離ラベル（近／遠）、属性ラベル（昼夜・遮蔽）を付与
- 難例優先ラベル（Active Learningで誤検知しやすいケースを重点）

### 2. 環境構築
- Python環境（Ultralytics YOLO、OpenCV、ffmpeg、pandas）
- 評価スクリプト（FN/FP率算出、混同行列、ヒステリシス挙動ログ）
- 実行環境: Mac mini or UbuntuノートPC

### 3. 試験実施
- 各条件で最低10イベント以上を実行
- 動体検知＋YOLO判定 → JSONログ出力
- 時系列多数決＋閾値分離でFN抑制
- ヒステリシス挙動を模擬イベントで確認

### 4. 評価・判定
- **近距離FN率:** 0%必達（未達なら撤退判断）
- **遠距離FN率:** 20%以下（許容範囲）
- **FP率:** 10%以下
- **ヒステリシス:** 1分以内に2回以上反転しないこと

### 5. 成果物
- PoC試験レポート
  - 距離別FN率
  - FP率
  - ヒステリシス安定度
  - 難例カタログ（見逃し傾向）
  - ラベリング負荷実績（イベント数、キーフレーム数）

---

## 撤退条件
- 近距離FNが1件でも発生した場合 → 開発中止判断可
- 遠距離FNが許容範囲を超える場合 → 設計見直し（音響センサー併用を必須に昇格）
- FP率が10%を超える場合 → 誤検知抑制ロジック再設計
