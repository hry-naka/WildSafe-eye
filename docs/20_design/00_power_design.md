# ✅ 電力設計書（v0.2）

**プロジェクト名:** WildSafe Eye  
**作成日:** 2025年11月14日  

---

## 1. 目的
- システムの稼働に必要な電力要件を定義し、PoC試験および実地利用に耐える構成を設計する。  
- 主電源（Jackery PTB152）を中心に、24時間以上の連続稼働を保証する。  
- 電力測定はPoC専用工程としては設けず、**ハードウェア作成段階およびフィールドテスト中に実測**する。

---

## 2. 前提条件
- **稼働環境:** キャンプ場（屋外）、昼夜連続稼働  
- **消費電力目標:** 平均2〜3W（ピーク時最大3W）  
- **稼働時間目標:** 24時間以上  
- **主電源:** Jackery ポータブル電源 PTB152（容量 1534Wh）  
- **補助電源:** EV給電（将来拡張候補として記録）  
- **切替方式:** 自動切替は行わず、設置時に選択。EV給電は現時点では除外

## 4. 電源設計
- **主電源:**  
  - Jackery PTB152 → 2.5W負荷で約600時間稼働可能  
  - 実効稼働時間は効率・待機電力を考慮し、300〜500時間を想定  

- **補助電源（将来拡張候補）:**  
  - EV給電（V2Lアダプタ） → 信頼性・コスト・運用性の観点から現時点では除外  
  - 将来の拡張条件：安全性が確認された製品が5万円以下で入手可能になる場合など

- **電源管理:**  
  - Jackery本体に過放電防止・過電流保護機能あり  
  - 純正ソーラーパネル・ACアダプタ使用時は逆流防止対策不要  
  - 外部電源との接続は現時点では行わないため、追加保護回路は不要

---

## 5. 設計課題
- **電源容量でピーク負荷・夜間稼働をカバーできるか？**  
  - 現状の構成（Jackery PTB152）で24h稼働は十分可能と見込む  
  - カバーできない場合の選択肢：  
    - ポータブル電源の容量増強（1000Wh→2000Wh級）  
    - 夜間の段階3抑制（強光・音の制限）  
    - IR照明の間欠制御

## 📎 アペンディクスC：電源管理仕様

| 項目         | 内容 |
|--------------|------|
| 閾値設定     | ポータブル電源残量20%以下で目視警告（LCD表示） |
| 警告方法     | 電源異常時は段階1警告を抑制し、**目視確認による運用とする**。ログ記録は行わない。 |
| 切替条件     | EV給電は現時点では除外。ポータブル電源を主電源として使用 |
| 切替方式     | 自動切替は行わず、設置時に選択。切替ログは記録対象外 |
| 再起動条件   | 電源切替後、システム再起動不要。電源系統はホットスワップ対応とする（要PoC確認） |
