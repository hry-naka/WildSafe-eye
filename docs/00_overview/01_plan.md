# プロジェクト計画（改訂版）

## 直近スプリント計画

- Sprint-1 (2025/11/10〜2025/11/28)
  - ゴール: 正常性チェックの完了（データ取得・リサイズ・保存・工数測定）
  - 成果物: 正常性チェックログ、工数測定レポート
  - 判定基準:
    - raw/resized データが正しく保存されていること
    - 100枚ごとの人力チェック工数が記録されていること
    - アノテーションはスコープ外

- Sprint-2 (2025/12/01〜2025/12/12)
  - ゴール: 公開データ（Open Images 等）を用いた分類器ベータ版の実装
  - 成果物: 識別器コード、初期モデル、動作ログ
  - 判定基準:
    - 熊クラスを含む公開データで分類器が動作すること
    - FP/FNを算出できる状態になっていること

- Sprint-3 (2025/12/15〜2025/12/26)
  - ゴール: Sprint-2成果の評価（分類タスクでのFP/FN定量化、精度観察）
  - 成果物: 評価レポート、難例カタログ
  - 判定基準:
    - FP/FNを定量的に算出できること
    - 誤検知・見逃しの傾向が整理されていること

- Sprint-4 (2026/01/05〜2026/01/16)
  - ゴール: 独自性データの収集方法の確立
  - 成果物: データ収集手順書、背景データセット
  - 判定基準:
    - 現場環境に即したデータ収集方法が確立されていること
    - 誤検知要因を含む背景データが収集されていること

- Sprint-5 (2026/01/19〜2026/01/30)
  - ゴール: 独自性データのアノテーション方法の確立
  - 成果物: アノテーション手順書、ツール選定レポート
  - 判定基準:
    - アノテーションツールとワークフローが確立されていること
    - ラベル付け基準が明文化されていること

- Sprint-6 (2026/02/02〜2026/02/13)
  - ゴール: 距離推計の導入（検出結果から距離を算出）
  - 成果物: 距離推計スクリプト、距離別リコールログ
  - 判定基準:
    - 検出座標から距離を推定できること
    - 距離別にリコール率を算出できること

- Sprint-7 (2026/02/16〜2026/02/27)
  - ゴール: ヒステリシス挙動の安定性確認（距離に応じた警報レベル制御）
  - 成果物: ヒステリシスログ、安定度評価レポート
  - 判定基準:
    - 識別器が安定した挙動を示すこと

## Backlog

1. **ラベル付けスクリプト改修**  
   - 検索キーワード依存から、人力で付けたvariationタグを参照するように改修  
   - 検索キーワードは補助的なメタ情報として残す  

2. **チェックリストテンプレート出力スクリプト改修**  
   - 正例／負例の観点を反映できるように修正  
   - variationタグやカテゴリ分類を出力に含める  

3. **ラベルCSVの座標対応**  
   - `make_labels_csv.py` を拡張し、アノテーション済み画像から `x1,y1,x2,y2` を含むラベルCSVを生成できるようにする  
   - YOLO形式の `.txt` または Pascal VOC形式の `.xml` をパースして統合する  

4. **物体検出評価スクリプトの拡張**  
   - `evaluate_fpfn.py` を物体検出タスクに対応させ、IoU計算による FP/FN 評価が可能なようにする  
   - `labels.csv` に座標がある場合は矩形ベースで評価、ない場合は分類評価にフォールバックする  

5. **距離推計モジュール**  
   - 検出座標とカメラパラメータから対象までの距離を算出する  
   - 距離別に警報レベルを設定できるようにする  

6. **ヒステリシス挙動制御**  
   - 距離推計結果を用いて警報レベルを段階的に変化させる  
   - 誤検知や過剰警報を抑制するための安定化ロジックを導入する  

7. **独自性データの拡張収集**  
   - 現場環境に特化した追加データを継続的に収集  
   - 公開データと組み合わせてモデルを改善する  
   - 誤検知要因（人間、犬、環境要素）を重点的に収集
